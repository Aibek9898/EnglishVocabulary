# Vocab Trainer

Личный сайт для изучения английских слов и фраз (уровень Upper-Intermediate).
Интервальное повторение по алгоритму FSRS, упражнения от узнавания до собственного предложения, игры и прогресс.
Работает целиком в браузере: без сервера, без регистрации, данные хранятся у тебя.

Подробный план и советы экспертов: [docs/PLAN.md](docs/PLAN.md).

## Запуск на компьютере

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет терминал (обычно http://localhost:5173).

## Заниматься с телефона

Пока сайт работает только у тебя на компьютере:

1. Телефон и компьютер должны быть в одной Wi-Fi сети.
2. Запусти `npm run dev`. В терминале будет строка `Network: http://192.168.x.x:5173`.
3. Открой этот адрес в браузере телефона.

У телефона и компьютера **отдельные копии** слов и прогресса. Чтобы перенести прогресс, сделай на одном устройстве Settings → Export backup, а на другом Settings → Restore from backup.

Когда сайт будет выложен в интернет (например на GitHub Pages), его можно будет установить на телефон как приложение: «Поделиться» → «На экран Домой».

## Как устроено

- **Today**: ежедневная тренировка. В ней повторение слов, которым пора, 7 новых слов в день и упражнение «напиши своё предложение».
- **Practice**: игры, которые не меняют расписание повторений: пары на время, быстрый тест, печать по памяти, диктант, карточки.
- **Library**: все слова, поиск, редактирование, готовые наборы (Packs).
- **Add**: добавить слово вручную или вставить ответ из Claude / Gemini (вкладка “From an AI chat”: скопируй промпт, вставь ответ ИИ).
- **Progress**: слова, которые можешь использовать, серия дней с «заморозками», календарь активности, уровни.

Уровни слова: 0 New → 1 Seen → 2 Recognised → 3 Recalled (напечатал сам) → 4 Used (написал своё предложение) → 5 Mastered (помнишь стабильно 3 недели и дольше).

## Свои наборы слов

Наборы лежат в `src/data/decks/*.json`. Новый файл в том же формате появится во вкладке Library → Packs.
В примере цель обрамляется квадратными скобками: `"We need to [make a decision] by Friday."`
