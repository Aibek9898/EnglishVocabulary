# Vocab Trainer

Личный сайт для изучения английских слов и фраз (уровень Upper-Intermediate).
Интервальное повторение по алгоритму FSRS, упражнения от узнавания до собственного предложения, игры и прогресс.
Работает целиком в браузере, без сервера: слова и прогресс хранятся на твоём устройстве.

Подробный план и советы экспертов: [docs/PLAN.md](docs/PLAN.md).

## Запуск на компьютере

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет терминал (обычно http://localhost:5173).

## Заниматься с телефона

Если запускаешь сайт у себя на компьютере:

1. Телефон и компьютер должны быть в одной Wi-Fi сети.
2. Запусти `npm run dev`. В терминале будет строка `Network: http://192.168.x.x:5173`.
3. Открой этот адрес в браузере телефона.

У телефона и компьютера **отдельные копии** слов и прогресса. Чтобы перенести прогресс, сделай на одном устройстве Settings → Save backup, а на другом Settings → Restore.

## Сайт в интернете (GitHub Pages)

После каждого push сайт сам собирается и выкладывается по адресу https://aibek9898.github.io/EnglishVocabulary/ (workflow `.github/workflows/deploy.yml`).
Один раз нужно включить: Settings → Pages → Source: **GitHub Actions**.

На телефоне открой этот адрес и добавь на главный экран («Поделиться» → «На экран Домой» в Safari, «Установить приложение» в Chrome): сайт будет открываться как отдельное приложение.

## Вход

Перед сайтом стоит экран входа (логин `aibek`). В коде хранится только «соль» и хэш пароля (PBKDF2, 600 000 итераций), сам пароль нигде не записан.
Это защита от случайных посетителей, а не настоящая безопасность: у статического сайта нет сервера, и разбирающийся человек может обойти вход, прочитав код.

Сменить пароль:

```bash
npm run set-password   # спросит новый пароль и обновит src/lib/auth.ts
git commit -am "Change password" && git push
```

## Как устроено

- **Today**: ежедневный урок. Новое слово проходит три шага: знакомство, узнавание и, через несколько заданий, ввод по памяти. Повторения подбираются по алгоритму FSRS: пропуск в предложении, перевод пропуска с русского, ввод по памяти, «скажи вслух» для хорошо знакомых слов. Ошибка разбирается сразу («You wrote / Answer», типичные ловушки для русскоговорящих), и слово возвращается в том же уроке. Подсказка засчитывается как «не вспомнил». В конце урока можно написать короткое сообщение с изученными фразами и скопировать его для проверки в Claude или Gemini.
- **Practice**: игры, которые не меняют расписание повторений, но засчитываются в серию дней: Natural or not? (60 секунд), Make / do / take / have, Find the mistake, Build the sentence, Role-play (15 жизненных ситуаций), пары на время, быстрый тест, печать по памяти, диктант, карточки.
- **Library**: все слова с поиском и фильтрами, карточка слова (написать своё предложение, «я использовал это в жизни», редактировать, скрыть, начать заново), готовые наборы (Packs).
- **Add**: добавить слово вручную или из чата с Claude / Gemini (вкладка “From an AI chat”: скопируй промпт, вставь ответ ИИ, выбери слова).
- **Progress**: слова, которые можешь использовать, серия дней с «заморозками», календарь активности, уровни.
- **Settings**: сколько новых слов в день, интенсивность повторений, тема (светлая / тёмная / как в системе), голос, резервная копия.

Уровни слова: 0 New → 1 Seen → 2 Recognised → 3 Recalled (напечатал сам) → 4 Used (написал своё предложение и потом вспомнил слово в другой день) → 5 Mastered (помнишь стабильно 3 недели и дольше).

## Свои наборы слов

Наборы лежат в `src/data/decks/*.json`. Новый файл в том же формате появится во вкладке Library → Packs.
В примере цель обрамляется квадратными скобками: `"We need to [make a decision] by Friday."`
Поле `wrong` хранит типичные ошибки в той же форме, что и текст в скобках (`["did a mistake"]`); их используют игры и разбор ошибок.
Если поменяешь готовые наборы, увеличь `PACKS_VERSION` в `src/lib/decks.ts`: тогда у тебя в браузере слова обновятся, а прогресс сохранится.
