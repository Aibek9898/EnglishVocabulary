# План сайта для изучения английских слов и фраз

Уровень: Intermediate / Upper-Intermediate (B1–B2). Родной язык: русский.
Главная цель: не просто узнавать слова, а **использовать** их в речи и письме.

План собран из советов трёх экспертов: учёного по усвоению языка и памяти, преподавателя английского (CELTA/DELTA) и дизайнера обучающих игр.

---

## 1. Главные принципы (с чем согласны все три эксперта)

1. **Учим фразы, а не отдельные слова.** Основная единица на карточке: «make a decision», «run out of time», «depend on». Готовые фразы составляют 30–50% живой речи.
2. **Вспоминать, а не перечитывать.** Самые полезные упражнения такие: напечатать слово по памяти, заполнить пропуск, перевести с русского. Выбор из вариантов годится только на первых встречах со словом.
3. **Интервальное повторение по алгоритму FSRS.** Он современнее, чем SM-2 в Anki, и требует примерно на 20–30% меньше повторений. Работает прямо в браузере.
4. **Без перегруза.** 5–10 новых слов в день. Если повторений накопилось слишком много, сайт сам перестаёт давать новые слова. Завал повторений — главная причина, по которой бросают.
5. **Слово выучено, только когда ты сам его использовал**, например написал своё предложение. Просто узнать его недостаточно.
6. **Не учить похожие слова в один день.** Если пройти вместе look up, look after и look into, они путаются. Группировать лучше по ситуациям («в аэропорту», «на работе»), а не по синонимам.
7. **Русский перевод нужен**, но как подсказка: на сложных уровнях он прячется.

## 2. Карточка слова или фразы

| Поле | Пример |
|---|---|
| Фраза | make a decision |
| Пример в контексте | I need to make a decision by Friday. |
| Русский эквивалент | принять решение |
| Определение на английском | to choose what to do after thinking |
| Частые сочетания | make / reach / put off a decision; a tough / final decision |
| Грамматика | decide **to do** sth |
| Ловушка для русскоговорящих | ❌ take/accept a decision (калька с «принять») |
| Произношение | озвучка браузером + транскрипция |
| Моё предложение | пишешь сам, это самое ценное поле |
| Источник | сериал, статья, работа… |
| Теги | work, phrasal verb, false friend… |

Каждая карточка тренируется в две стороны: с английского на смысл (легче) и с русского на английский (сложнее, но именно это даёт активный словарь).

## 3. Уровни освоения слова (0–5)

| Уровень | Название | Как перейти дальше |
|---|---|---|
| 0 | Новое | познакомился с карточкой |
| 1 | Видел | угадал в выборе из вариантов |
| 2 | Узнаю | выбрал правильно несколько раз |
| 3 | Вспоминаю | напечатал сам: пропуск или перевод с русского |
| 4 | **Использую** | написал своё предложение или сообщение с этим словом |
| 5 | Освоено | вспоминаешь стабильно через месяц и дольше |

Главная цифра на сайте: **«Слова, которые я могу использовать»** (уровень 4 и выше).

## 4. Упражнения и игры

**Основа (вспоминание):**
1. **Флеш-карточка**: сначала вспоминаешь, потом открываешь ответ и отмечаешь «Не помню» или «Помню».
2. **Пропуск в предложении**: убрана вся фраза, «I need to ___ ___ decision», первую букву можно показать подсказкой.
3. **Перевод с русского**: «Я принял решение уйти» → «I made the decision to leave».
4. **Выбор из вариантов с похожими ловушками**: affect/effect, make/do. Только для новых слов.
5. **Диктант**: слушаешь фразу и печатаешь её.

**Игры:**
6. **Найди пары на время**: 5 пар за раунд, хорошо для разминки.
7. **Собери фразу**: кусочки идиомы или фразы перемешаны.
8. **Make или do?** Сортируешь существительные по глаголам: make / do / take / have.
9. **Ложные друзья**: magazine ≠ магазин, actual ≠ актуальный, sympathetic ≠ симпатичный.
10. **Найди ошибку**: «I did a mistake», «it depends from…».
11. **Быстрый раунд**: 60 секунд, только для хорошо знакомых слов.
12. **Босс**: отдельный раунд для «трудных» слов, которые ты забывал много раз.

**Практика (использование):**
13. **Своё предложение**: «Напиши о своей работе, используя *put off*».
14. **Три слова за день**: короткое сообщение другу о своём дне с тремя словами на повторении.
15. **Мини-история**: 5 слов, 5–7 предложений. Истории сохраняются, перечитывать их полезно.
16. **Ролевой диалог** (с ИИ, позже): ИИ играет арендодателя, интервьюера или коллегу, а ты стараешься вставить нужные фразы. Они отмечаются галочками.
17. **Кнопка «Использовал в жизни»**: отметка, что ты сказал или написал это где-то по-настоящему.

Проверка практики без ИИ: сайт проверяет, что нужное слово есть в тексте, показывает примеры и даёт оценить себя самому. С ИИ (необязательно) ты получаешь 1–2 исправления и улучшенный вариант без лишней критики. Твои ошибки превращаются в новые карточки («Мои ошибки»).

---

## 5. Ежедневная тренировка (10–15 минут)

1. **Разминка**, 1 мин: «найди пары» по недавним словам.
2. **Повторение**, 5–7 мин: слова, которым пора. Тип упражнения подбирается по уровню слова. Не больше ~40 повторений, остальные переносятся на завтра.
3. **Новые слова**, 3 мин: 5–10 штук с примером, озвучкой и сразу короткой проверкой.
4. **Игра**, 2–3 мин: каждый день другая (make/do, собери фразу, диктант).
5. **Практика**, 2 мин: «три слова за день» или своё предложение.
6. **Итог**: «+3 слова, которые можешь использовать», отметка в календаре.

Отдельная кнопка «У меня 3 минуты» запускает только повторение.

---

## 6. Прогресс и мотивация

**Что показываем:**
- Сколько слов «могу использовать» (главная цифра)
- Календарь активности, как на GitHub
- Серию дней с «заморозками»: одна заморозка за каждые 7 дней, максимум 2; день засчитывается уже при 5 повторениях
- Процент запоминания и сколько повторений завтра
- Сравнение с самим собой на прошлой неделе
- Осмысленные достижения: «100 слов, которые можешь использовать», «первая история»

**Чего избегаем:**
- Таблиц лидеров
- «Жизней», которые блокируют учёбу
- Давящих напоминаний
- Очков за лёгкие задания

**Раз в месяц проверка:** короткий тест на случайных словах, которого алгоритм повторения не видит. Он показывает настоящий прогресс.

---

## 7. Откуда берутся слова

- **Быстрое добавление**: фраза, предложение, где ты её встретил, и источник. Это главный способ: слова из твоей жизни запоминаются лучше всего.
- **Готовые тематические наборы** для дней без новых слов: работа и встречи, путешествия, чувства, деньги, здоровье. В них частотные фразовые глаголы и устойчивые сочетания.
- **Импорт и экспорт** CSV/JSON, например чтобы перенести слова из Anki или из таблицы.

## 8. Техническая часть

| Что | Решение | Почему |
|---|---|---|
| Сайт | React + TypeScript + Vite | быстрый, популярный, легко менять под себя |
| Хранение | IndexedDB в браузере (библиотека Dexie) | без сервера и базы, всё работает локально |
| Резервная копия | экспорт и импорт в файл JSON | чтобы не потерять слова |
| Повторение | библиотека `ts-fsrs` | готовый алгоритм FSRS |
| Озвучка | встроенная в браузер (Web Speech API) | бесплатно, без интернета |
| Телефон | PWA (сайт ставится на телефон как приложение) | можно заниматься с телефона |
| Хостинг потом | GitHub Pages / Netlify / Vercel | бесплатно, ведь это статический сайт |
| ИИ (позже) | Claude API по твоему ключу, по желанию | проверка предложений, диалоги, генерация примеров |

Запуск локально: `npm install`, затем `npm run dev`, и сайт открывается на `localhost`.

Если позже захочется синхронизировать данные между компьютером и телефоном, добавим маленький сервер. Структура данных это позволит.

## 9. Этапы

**Этап 1 — основа (MVP):**
- Карточки слов и фраз: добавление, редактирование, теги
- Импорт и экспорт
- Алгоритм FSRS
- Флеш-карточка, пропуск, перевод с русского, выбор из вариантов, пары, диктант
- Уровни 0–5 и счётчик «могу использовать»
- Календарь активности, серия дней с заморозками
- Ежедневная тренировка
- Первый готовый набор фраз

**Этап 2 — практика и игры:**
- Своё предложение, «три слова за день», мини-истории
- Make/do, ложные друзья, найди ошибку, собери фразу
- «Мои ошибки», статистика и графики, настройка целей

**Этап 3 — ИИ и удобства:**
- Проверка текстов ИИ и ролевые диалоги
- Генерация примеров
- Быстрый раунд и «босс»
- Месячный тест
- PWA для телефона
- Хостинг
